# Add a library

1. Check the approved list in CLAUDE.md. If the package is listed, go ahead.
2. If not, stop and ask the owner with:
   - Package name and what it does, in one sentence.
   - Why it is needed for this stage.
   - The no-library alternative and its trade-off.
3. Wait for a yes. Never install first and ask later.
4. After approval, install it, and add it to the approved list in CLAUDE.md.
